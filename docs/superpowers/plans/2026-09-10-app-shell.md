# Milestone 1 App Shell Implementation Plan

> **For agentic workers:** Execute this small plan inline using Superpowers' execution and verification guidance. Track completion below.

**Goal:** Launch a native macOS menu bar app with explicit Ready/Recording state and working menu controls.

**Architecture:** A SwiftUI `MenuBarExtra` observes a main-actor `AppState`. The state object owns transitions; the view sends start/stop actions. A regular Xcode app target builds the bundle, with no third-party dependencies.

**Tech Stack:** Swift, SwiftUI, AppKit, Xcode 26.6; macOS 26 minimum.

**Spec:** [MVP_SPEC.md](../../../MVP_SPEC.md%20%E2%80%94%20Native%20macOS%20Dictation%20App%20v0.1.md), Milestone 1 only.

## Global Constraints

- Run as a native macOS application.
- Live primarily in the macOS menu bar.
- Represent application state explicitly.
- UI does not own business logic.
- No speech functionality yet.
- No microphone, Speech Recognition or Accessibility permission requests in this milestone.
- Display that the microphone is off; the recording state is a shell preview.
- Build with local ad-hoc signing and a stable bundle identifier. App Sandbox remains disabled for the later Accessibility insertion service.

## Task 1: Native app shell

**Files:** `VoiceApp.xcodeproj/project.pbxproj`, shared `VoiceApp` scheme, `VoiceApp/App/VoiceApp.swift`, `VoiceApp/App/AppState.swift`, `VoiceApp/Models/DictationState.swift`, `VoiceApp/UI/MenuBarView.swift`, `VoiceApp/Info.plist`, `.gitignore`, `README.md`.

**Interfaces:** `AppState.state: DictationState` is externally read-only. `startRecording()` transitions idle to recording; `stopRecording()` returns recording to idle. Repeated start/stop calls leave the state unchanged. No service runs in this milestone.

- [x] Create an Xcode macOS application target and shared scheme. Set `LSUIElement` to true, the bundle ID to `com.williamt.voiceapp`, and the deployment target to macOS 26.
- [x] Implement the two-state enum and main-actor observable coordinator. Keep transition logic outside the view.
- [x] Implement a menu showing Ready or Recording (preview), a Start/Stop Dictation button, microphone-off notice, and Quit. Use microphone/stop SF Symbols in the menu bar, with accessible text labels.
- [x] Document the build command, app location, current limitations, and manual acceptance checks.
- [x] Build Debug with `xcodebuild -project VoiceApp.xcodeproj -scheme VoiceApp -configuration Debug -derivedDataPath build build`.
- [ ] Launch the built `.app`; inspect Ready, Start → Recording, Stop → Ready, a second cycle, and Quit. Confirm no main window or Dock icon and no permission prompt.
- [x] Review source and bundle metadata, mark actual verification results, and leave the app running for the user. Its initial state is Ready in source; the visible state still requires the pending menu check.
